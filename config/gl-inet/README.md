# GL-iNet A-1300 configs

All 14 routers in this network are the same model (GL-iNet A-1300 / Slate Plus) — the 12
theatre routers, plus both VMix nodes' routers. One config file each:

- `theatre-N.uci` (×12), generated by [`generate-configs.sh`](generate-configs.sh) from
  [`theatre-network.uci.template`](theatre-network.uci.template)
- `vmix-node-N.uci` (×2), generated from [`vmix-node-network.uci.template`](vmix-node-network.uci.template)

Both cover the core network config only: LAN bridge (both LAN ports bridged together — see
[`docs/topology.md`](../../docs/topology.md) for why LAN 1/LAN 2 are still one subnet on
the theatre routers), WAN as a DHCP client, and static DHCP leases for the fixed-IP
devices in [`docs/ip-address-map.md`](../../docs/ip-address-map.md).

**Not covered here** — apply separately per GL-iNet's own web UI: Wi-Fi (should be
disabled or locked down per venue policy), the Tailscale connection itself (use
[`config/tailscale-up-commands.sh`](../tailscale-up-commands.sh) or the fully-instantiated
[`config/tailscale-up-all-devices.sh`](../tailscale-up-all-devices.sh)), and firmware/VPN
policy settings.

**Before applying:** replace every `REPLACE_WITH_MAC_nn` placeholder with that device's
real MAC address — the static leases won't do anything useful until you do.

## Applying a config

SSH into the router (theatre or VMix node) and either merge the relevant stanzas into
`/etc/config/network` and `/etc/config/dhcp` by hand, or:

```sh
scp theatre-N.uci root@192.168.X.1:/tmp/theatre-N.uci      # or vmix-node-N.uci -> 192.168.20.1 / .21.1
ssh root@192.168.X.1
# review /tmp/theatre-N.uci, then apply the network/dhcp sections it contains
# to /etc/config/network and /etc/config/dhcp respectively, then:
/etc/init.d/network restart
/etc/init.d/dnsmasq restart
```

## Regenerating

```sh
./generate-configs.sh
```

Regenerates all 12 `theatre-N.uci` files plus both `vmix-node-N.uci` files from their
templates — re-run after editing either template rather than hand-editing the generated
files.
