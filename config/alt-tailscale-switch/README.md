# Alternative: plain switch + Tailscale on generic Linux (not GL-iNet)

**Not the recommended approach** — see [`docs/topology-alternative-tailscale-switches.md`](../../docs/topology-alternative-tailscale-switches.md)
for the full reasoning. Documented here for completeness as a real alternative to
[`config/gl-inet/`](../gl-inet/), same theatre topology, different hardware.

- `theatre-N-alt.sh` (×12), generated by [`generate-configs.sh`](generate-configs.sh) from
  [`theatre-network-alt.template`](theatre-network-alt.template) — NAT (nftables) + DHCP
  (dnsmasq) + interface setup, replacing what a GL-iNet ships built-in.
- **Tailscale invocation is unchanged** — reuse [`../tailscale-up-all-devices.sh`](../tailscale-up-all-devices.sh)
  as-is; Tailscale doesn't care what hardware runs it.
- Requires 2 NICs per box (one direct to the ATEM, one to a switch for everything else) to
  replicate the dedicated ATEM port the GL-iNet gives for free.
- **Before applying**: replace every `REPLACE_WITH_MAC_nn`, adjust NIC names (`lan0`/`lan1`/
  `wan0`) to match the actual box, and confirm nftables/dnsmasq versions match your distro.
